# Security policy

Report suspected vulnerabilities privately to contact+github@madansapkota.com, the maintainer contact listed in the package metadata. Include the package version, runtime, timezone, affected input and a small, bounded reproduction. Do not include credentials or personal data, or open a public issue with unpatched exploit details.

Security fixes target the latest release. Users of older releases should upgrade when a fix is available. Reports are reviewed by the maintainer; no response-time guarantee is provided. Coordinate public disclosure after a fix and affected-version guidance are available.
